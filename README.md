# ماشین حساب مهندسی و تبدیل واحد

یک ابزار رایگان و فارسی، مناسب موبایل و کامپیوتر؛ بدون نصب و بدون هاست پولی.

## اجرای آنلاین
https://mohammadshahshahi.github.io/calculator/

## ماشین حساب مهندسی
- عملیات پایه: جمع، تفریق، ضرب و تقسیم
- توابع مثلثاتی: sin، cos، tan و معکوس آن‌ها
- انتخاب درجه (DEG) یا رادیان (RAD)
- ریشه دوم، توان، فاکتوریل و درصد
- لگاریتم طبیعی و ده‌دهی، قدرمطلق
- ثابت‌های π و e و پرانتزها
- پشتیبانی از صفحه‌کلید و نمایش خطاهای ورودی

## تبدیل واحد
دسته‌بندی‌ها:
- طول، جرم، مساحت و حجم
- دما (سلسیوس، فارنهایت و کلوین)
- زمان و سرعت
- داده (bit، byte و واحدهای ده‌دهی و دودویی)
- فشار و انرژی

## نسخه پایتون
برای اجرای ماشین حساب خط فرمان:
```bash
python calculator.py
```

اجرای تست‌ها:
```bash
python -m unittest discover -v
```
