# ماشین‌حساب ساده پایتون

یک ماشین‌حساب خط فرمان با زبان Python.

## امکانات
- جمع، تفریق، ضرب و تقسیم
- مدیریت تقسیم بر صفر
- بررسی ورودی‌های نامعتبر
- خروج با وارد کردن `q`

## اجرا
```bash
python calculator.py
```

## اجرای تست‌ها
```bash
python -m unittest discover -v
```

GitHub Actions با هر Push به شاخه `main` و هر Pull Request تست‌ها را خودکار اجرا می‌کند.
