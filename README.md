# ماشین‌حساب ساده

یک پروژه رایگان شامل **ماشین‌حساب تحت وب مناسب موبایل** و **نسخه خط فرمان پایتون**.

## استفاده سریع از نسخه وب
پس از فعال شدن GitHub Pages، ماشین‌حساب از این نشانی در دسترس خواهد بود:

https://mohammadshahshahi.github.io/calculator/

نسخه وب روی موبایل و کامپیوتر اجرا می‌شود و به نصب برنامه یا هاست پولی نیاز ندارد.

## امکانات نسخه وب
- رابط فارسی و راست‌چین، واکنش‌گرا برای موبایل
- جمع، تفریق، ضرب و تقسیم
- اعشار، تغییر علامت و حذف رقم
- پشتیبانی از صفحه‌کلید
- مدیریت تقسیم بر صفر

## اجرای نسخه پایتون
به Python 3 نیاز دارید:

```bash
python calculator.py
```

برای خروج، در ورودی عدد اول `q` را وارد کنید.

## اجرای تست‌ها
```bash
python -m unittest discover -v
```

شش تست خودکار برای عملیات اصلی و خطاها در پروژه وجود دارد. GitHub Actions آن‌ها را با هر Push و Pull Request اجرا می‌کند.

## انتشار رایگان
نسخه وب با GitHub Pages و GitHub Actions منتشر می‌شود. کدهای پروژه تحت مجوز MIT هستند.


نسخه وب: https://mohammadshahshahi.github.io/calculator/
